# مُستبين (Mostabeen)

تطبيق عربي لتحليل ملفات الاستبانات داخل المتصفح: جودة البيانات، الاختبارات الإحصائية، ثبات المقياس، فحص الامتثال، وتقرير جاهز. لا يُرفع الملف إلى أي خادم.

نسخة أولى. اقرأ قسم «ما لا يفعله» قبل الاعتماد عليه في قرار مهم.

## التشغيل

افتح `index.html` (صفحة الهبوط) أو `app.html` (التطبيق) في المتصفح مباشرة، أو فعّل GitHub Pages على الفرع الرئيسي.

يحتاج التطبيق اتصالاً بالإنترنت لتحميل الخطوط ومكتبة قراءة Excel. ملفات CSV والنص الملصوق تعمل بدونه.

## البنية

| المسار | المحتوى |
|---|---|
| `src/app.html` | مصدر التطبيق: الواجهة والمحرك الإحصائي في ملف واحد |
| `src/landing.html` | مصدر صفحة الهبوط |
| `build.js` | يولّد `app.html` و `index.html` من المصدرين |
| `tests/` | اختبارات المحرك الإحصائي مقابل قيم مرجعية |

بعد تعديل أي ملف في `src/`:

```bash
node build.js
```

```bash
node tests/stats.test.js
```

## ما يفعله

- **القراءة:** CSV و Excel ونص ملصوق، مع تعرّف آلي على مقاييس ليكرت العربية والإنجليزية وأسئلة التوصية (0–10) والنصوص المفتوحة.
- **الجودة:** المفقود، الصفوف المكررة، الإجابة النمطية، الإجابات المتعجّلة، هامش الخطأ.
- **الإحصاء:** مربع كاي، كروسكال–واليس، ت لويلش، تحليل التباين الأحادي، سبيرمان وبيرسون، ألفا كرونباخ، حجم الأثر، وتصحيح بنجاميني–هوكبرغ للمقارنات المتعددة.
- **الامتثال:** رصد البيانات الشخصية بالأنماط (بريد، هاتف، هوية، IP، عناوين الأعمدة)، حساب k لإعادة التعرّف، الخلايا الصغيرة، قائمة ضوابط استرشادية، وتنزيل نسخة بلا المعرّفات المباشرة المرصودة.
- **التقرير:** ملخص تنفيذي، إفصاح منهجي، نتائج، وحدود التحليل. يُنزَّل HTML و Excel.

## ما لا يفعله

- لا ينشئ استبانات ولا يوزّعها.
- يقرأ صف عناوين واحداً فقط، ولا يفصل أسئلة الاختيار المتعدد.
- لا يرصد اسم شخص داخل نص مفتوح، ولا يزيل المعرّفات شبه المباشرة من الملف المُنزَّل.
- لا انحدار ولا تحليل عاملي ولا مقارنات بعدية ولا ترجيح للعينة.
- لا حسابات ولا حفظ ولا عمل جماعي.
- تحليل النصوص عدّ كلمات فقط.
- لم يُختبر على ملفات كبيرة.
- فحص الامتثال قائمة استرشادية، وليس شهادة ولا رأياً قانونياً.
- لم يدقّق المحرك الإحصائي طرف مستقل.
